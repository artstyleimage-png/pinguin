# Penguin Brawl 🐧

Мультиплеерная 3D-игра в браузере: пингвины на квадратной льдине посреди океана.
Последний пингвин, оставшийся на льду, побеждает и получает новый скин.

## Как играть

1. Открой игру — попадёшь в лобби (в стиле Fortnite): твой пингвин на льдине, рядом друзья из пати.
2. Нажми **ИГРАТЬ** — начнётся поиск матча (до **10** игроков). Если людей мало, место займут боты.
3. Все появляются на льдине и **не могут двигаться**. У всех есть **10 секунд**: веди мышкой (или пальцем)
   по льду — за пингвином тянется стрелка. Длина стрелки = сила толчка.
4. Когда время вышло, все одновременно скользят туда, куда указывала стрелка. Пингвины не переворачиваются,
   а при столкновении физически отталкиваются (упругий удар с сохранением импульса).
5. Кто вылетел за край — падает в воду и выбывает. Раунды повторяются, с 3-го раунда льдина начинает таять.
6. Победитель получает случайный закрытый скин (редкие выпадают реже).

### Скины
Нажми на своего пингвина в лобби (или вкладку **ШКАФЧИК**), чтобы посмотреть коллекцию и надеть скин.
Закрытые скины показаны силуэтами — их можно получить только победами.

### Пати
- Каждый игрок сразу в своей пати. В пати максимум **4** человека.
- Чтобы позвать друга: «Скопировать ссылку» и отправь её, либо друг вводит **код пати** в поле «КОД ДРУГА».
- Друзья нажимают «ГОТОВ», лидер нажимает «ИГРАТЬ» — вся пати попадает в один матч.

## Penguin Parkour 🏔

Одиночный режим: кнопка **🏔 PARKOUR** в лобби (или страница `parkour.html`). Пингвин в твоём скине
пробегает трассы из льдин посреди океана — 4 трассы, открываются по очереди:

1. **Первые шаги** — прыжки, лестница, длинный и двойной прыжок.
2. **Скользкий путь** — гладкий лёд, движущиеся льдины, лифт и пружины.
3. **Тающие льдины** — трескающийся лёд и крутящиеся балки.
4. **Ледяная башня** — спиральный подъём на вершину айсберга.

Управление: **WASD/стрелки** — бег, **пробел** — прыжок (ещё раз в воздухе — двойной), **мышь** — камера
(клик захватывает курсор), **R** — к чекпоинту, **Esc** — пауза. На телефоне — джойстик и кнопка прыжка.
Упал в воду — возвращаешься на последний чекпоинт. За трассу до трёх звёзд: финиш, все рыбки 🐟 и время
быстрее контрольного. Рекорды хранятся в браузере.

## Запуск

Нужен Node.js 20.11+.

```bash
npm install
npm start          # http://localhost:3000
```

Чтобы играть с друзьями по интернету, разверни сервер на любом хостинге с поддержкой Node.js и WebSocket
(Render, Railway, Fly.io, VPS) — команда запуска `npm start`, порт берётся из переменной `PORT`.

### Настройки (переменные окружения)

| Переменная      | По умолчанию | Что делает |
|-----------------|--------------|------------|
| `PORT`          | `3000`       | Порт HTTP/WebSocket сервера |
| `QUEUE_WAIT_MS` | `12000`      | Сколько ждать игроков перед стартом матча |
| `MIN_PENGUINS`  | `6`          | До скольки пингвинов добивать матч ботами (`0` — без ботов, но минимум 2 участника) |
| `AIM_MS`        | `10000`      | Время на прицеливание |
| `INTRO_MS`      | `3500`       | Заставка перед первым раундом |
| `DATA_DIR`      | `./data`     | Где хранятся профили (победы и скины) |

## Устройство

- `server/` — Node.js (Express + `ws`). Сервер авторитетный: вся физика (скольжение с трением,
  столкновения дисков, падение в воду) считается на сервере 120 раз/с и рассылается клиентам 30 раз/с.
  Пати, матчмейкинг, боты и сохранение профилей тоже здесь.
- `public/` — клиент на Three.js без сборки: процедурная модель пингвина и скины, вода на шейдере,
  айсберги, ледяная арена, интерфейс лобби/шкафчика/матча.
- `shared/` — константы и список скинов, общие для сервера и клиента; физика и трассы паркура
  (`parkour-physics.js`, `parkour-levels.js`) — тоже здесь, без Three.js, чтобы их можно было тестировать в Node.
- `public/parkour.html`, `public/js/parkour/` — клиент паркура (сцена, камера, управление, интерфейс).

```bash
npm test   # интеграционные тесты сервера: пати, матчмейкинг, полный матч;
           # паркур: дальность прыжков и автопилот, который проходит каждую трассу
```
